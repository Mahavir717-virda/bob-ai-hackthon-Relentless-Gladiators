# `ml/experiments` — Model Training & Evaluation Notebooks

## Module Overview
Workspaces for model exploration, hyperparameter tuning, and metric verification.

- **Subdirectories:**
  - `ml/experiments/demand/` — Baseline vs. LightGBM comparisons, lag feature ablation.
  - `ml/experiments/renewable/` — Solar/wind curve modeling, anomaly score thresholds, SHAP summary plots.
  - `ml/experiments/optimization/` — MILP formulation testing and benchmark scenarios.
- **Rule:** Model claims must be supported by empirical validation results on held-out test splits.
