# `shared/types` — Common Domain Data Types

## Module Overview
Contains shared utility types, entity IDs, telemetry packets, and primitive domain models used across frontend, backend, and integration tests.

- **Contents:**
  - Asset identifiers and enums (`AssetType`, `SpikeSeverity`, `OptimizationStatus`).
  - Timeseries timestamps and window definitions.
  - Geo and substation topology metadata.
