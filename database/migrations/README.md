# `database/migrations` — Database Migrations

## Module Overview
Contains timestamped, reversible SQL migration scripts for database version control.

- **Naming Convention:** `YYYYMMDDHHMMSS_description.sql`
- **Runner:** Knex / Prisma / Flyway or standalone SQL migration runner.

- **Branch:** `leader/integration`
